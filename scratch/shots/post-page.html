From scratch is a good call — you learn more in one weekend than in a year of theme tweaking. Just know the HTML/CSS is the easy part; what WordPress quietly handed you was sitemaps, RSS, image resizing, forms and caching. A static generator like Astro or Eleventy gives you plain files plus those bits, content stays as Markdown in git, and Cloudflare Pages hosts it free. Reach for a database only once you actually need one.

Happy to help. One thing that removes most of that pain: build the layout with CSS Grid and Flexbox first, then add breakpoints only where the design actually breaks - not at fixed device widths. Most 'unresponsive layout' patches disappear once the base layout is fluid instead of pixel-locked. And every plugin you drop is one less thing to keep updated and audit later.
